## What It Is & Why Use It

**Hypn0** decomposes photos, logos, and graphics into procedural geometric shapes (circles, rings, diamonds, snowflakes, binary "0/1" code, stars, hearts) with individual per-element phase-shifted CSS keyframe animations.

The result is a clean, standalone `.svg` file (typically 20–50 KB) that runs natively in any browser with **zero JavaScript execution overhead**.

### Where to Use:
- **UI/UX & Web Design:** Lightweight animated preloaders, Hero background textures, interactive 404 backdrops, and Dark Mode atmospheric layers (replaces heavy GIFs and video loops).
- **Marketing & SMM:** Dynamic display banners, attention-grabbing CTA elements, podcast/album cover art, and YouTube thumbnails that overcome banner blindness.
- **Game Dev & Sci-Fi Interfaces:** Procedural terminals, radar displays, scanning grids, holographic force fields, and cyberpunk HUDs.
- **VJing & Live Streaming:** Animated stream overlays for OBS/Twitch and seamless generative visual loops for live performances.
- **CNC & Digital Fabrication:** Scalable vector paths for laser engraving, vinyl cutting, plotter drawing, and screen printing / apparel merch.

---

## Key Features

- **12+ Procedural Shapes:** circles, rings, diamonds, squares, triangles, hexagons, snowflakes, binary code, crosses, stars, hearts, and linear hatching.
- **Full Rasterization Control:** adjustable grid density, maximum radius, brightness, contrast, thresholding, monotone, duotone, and inverted color palettes.
- **Pure CSS @keyframes:** radius pulsation (breathing), luminescence flicker, rotation sway, and traveling wave effects without CPU rendering penalties.
- **Community Trance Gallery:** a three-tier curation system (*Incubator* &rarr; *Approved by Brain Slug* &rarr; *Deep Trance Hall of Fame*) powered by an automated logarithmic time-decay gravity ranking algorithm.
