# Hypn0 (HypnoSVG)

Процедурный генератор анимированной векторной полутоновой графики (halftone SVG). Превращает растровые изображения в масштабируемый векторный арт из пульсирующих геометрических матриц.

## Что это и зачем

**Hypn0** раскладывает фото, логотипы и графику на процедурные геометрические фигуры (круги, кольца, ромбы, снежинки, матрицы «0/1», звезды, сердца) с индивидуальной фазовой CSS-анимацией.

На выходе — чистый, легковесный `.svg` (20–50 КБ), работающий нативно без JavaScript на любых экранах.

### Где применять:
- **UI/UX и веб-дизайн:** Легкие анимированные прелоадеры, Hero-фоны лендингов, экраны 404 и Dark Mode подложки (вместо тяжелых GIF и видео).
- **Маркетинг и SMM:** Динамические баннеры, CTA-плашки, обложки треков/подкастов и YouTube-превью, пробивающие баннерную слепоту.
- **Геймдев и Sci-Fi:** Процедурные терминалы, радары, сканеры, силовые поля и HUD-интерфейсы.
- **VJing и стриминг:** Оверлеи для OBS/Twitch и бесшовные визуальные петли (VJ loops) для сцены.
- **ЧПУ и полиграфия:** Векторные контуры для лазерной гравировки, плоттерной резки и шелкографии/мерча.

## Ключевые возможности

- **12+ процедурных форм:** круги, кольца, ромбы, гексагоны, снежинки, бинарный код, кресты, звезды, сердца.
- **Полный контроль растеризации:** плотность сетки, радиус, пороги отсечения, дуотоновые и инверсные палитры.
- **Чистый CSS @keyframes:** дыхание, мерцание, волны и вращение без нагрузки на CPU.
- **Галерея сообщества:** трехуровневая система отбора (Инкубатор -> Выбор Мозгового Слизня -> Золотой фонд) с гравитационным алгоритмом рейтинга.
